Guía técnica

Cómo está armado el sistema y dónde vive cada parte.

1Las piezas del sistema

PiezaQué esDónde corre
AplicaciónPrograma de Windows (Python + PySide6) que usan cajeros y administradorEn cada computadora
APIServidor FastAPI con todas las reglas de cobro, caja y permisosRender (gratis)
Base de datosPostgreSQL con estudiantes, pagos, cajas y bitácoraSupabase (gratis)
CorreoEnvío de comprobantes y avisos de vencimientoMailjet (gratis)
Tareas automáticasRespaldo diario y mantener la API despiertaGitHub Actions (gratis)
La aplicación no guarda datos en la computadora: todo pasa por la API y queda en Supabase. Por eso varias computadoras ven la misma información y no hay que instalar ninguna base de datos.

2Cómo se conectan

Aplicación (.exe)  ──HTTPS──▶  API (Render)  ──▶  PostgreSQL (Supabase)
                                    └──▶  Mailjet (correos)

La aplicación sabe a qué API conectarse por el archivo config.json que va junto al .exe:

{ "api_base_url": "https://ctc-backend-j3id.onrender.com" }

3Reglas principales

  • Las colegiaturas vencen cada 28 días desde la fecha de inicio de clases (6 meses = 7 cuotas).
  • No se cobra sin una caja abierta; al cerrar se hace el arqueo y se justifica cualquier diferencia.
  • Cada cobro genera un comprobante con número correlativo (R-000001).
  • Un pago nunca se borra: se anula con motivo y queda en el historial.
  • 7 días antes del vencimiento se manda un correo de aviso al estudiante y a su responsable.
  • Las fechas usan la hora oficial de El Salvador.

4Usuarios y seguridad

  • Dos roles: Administrador (todo) y Cajero (matricular, cobrar y su propia caja).
  • Los permisos los revisa la API, no solo el menú de la aplicación.
  • Contraseñas cifradas (bcrypt) y sesiones con token (JWT) que expiran.
  • 5 intentos fallidos bloquean la cuenta 5 minutos.
  • La bitácora registra cobros, anulaciones, cierres y cambios de configuración.

5Configuración del servidor (Render)

Variables que se configuran en Render → Environment (nunca se suben al repositorio):

VariablePara qué sirve
DATABASE_URLConexión a la base de Supabase
SECRET_KEYFirma de las sesiones
MAILJET_API_KEY / MAILJET_API_SECRETEnvío de correos
EMAIL_FROM_ADDRESSCorreo que aparece como remitente
CRON_SECRETClave para la tarea diaria de avisos

Al arrancar, la API actualiza sola la estructura de la base de datos (migraciones Alembic).
