# Manual de usuario — CTC Campus

## Primer ingreso

1. Abre **CTC Campus** e inicia sesión con tu correo y contraseña.
2. Si tu contraseña es temporal (la asignó el administrador), el sistema te
   pedirá cambiarla antes de continuar. Debe tener al menos 6 caracteres, con
   letras y números.
3. Tras 5 intentos fallidos la cuenta se bloquea 5 minutos.

## Jornada del cajero

### 1. Abrir la caja

**Caja y cobros → Abrir caja.** Escribe el fondo inicial (el efectivo con el
que empiezas). Sin caja abierta el sistema no deja cobrar.

### 2. Registrar una matrícula

**Inscripciones → Nueva matrícula.** Un solo formulario:

1. **Estudiante:** *Estudiante nuevo* (llena sus datos; la edad se calcula
   sola; si es menor de 18 años, los datos del responsable son obligatorios)
   o *Estudiante ya registrado* (escribe para buscarlo).
2. **Datos de matrícula:** servicio (diplomado), horario, fecha de matrícula,
   **fecha de inicio de clases** (de ella salen todos los cobros: el primero
   ese mismo día y luego cada 28 días), tipo de matrícula, plan de
   colegiatura y observaciones.
3. **Cobro:** método de pago y **Efectivo:**; el sistema muestra el
   **Cambio:** al instante y no deja registrar si falta dinero.

Al registrar aparece el comprobante: **Imprimir ticket**, **Guardar PDF** o
**Enviar por WhatsApp**. El comprobante también llega por correo al
estudiante y a su responsable.

### 3. Cobrar una colegiatura

**Caja y cobros → 💵 Cobrar colegiatura** (o doble clic en un estudiante de la
lista *Cobros próximos y atrasados*).

1. Escribe el nombre del estudiante para buscarlo.
2. El sistema muestra qué cuota toca (ej. *Cuota 3 de 7*), su vencimiento,
   las cuotas vencidas y cuánto debe.
3. Elige cuántas cuotas paga (puede adelantar varias).
4. Si está atrasado, decide si aplicas el **recargo por mora** ($3.00).
5. Escribe el **Efectivo:** y entrega el **Cambio:** que indica el sistema.

### 4. Estar pendiente de los cobros

El panel **Cobros próximos (7 días) y atrasados** está siempre visible en
*Caja y cobros*: situación, cuotas vencidas, monto a cobrar y si ya se le
envió el aviso por correo. **Avisar por WhatsApp** abre WhatsApp con el
mensaje ya escrito. El sistema envía solo el aviso por correo 7 días antes.

### 5. Reimprimir un comprobante

En la lista de pagos, botón **Ticket** de la fila.

### 6. Cerrar la caja

**Caja y cobros → Cerrar caja (arqueo).** Cuenta los billetes y monedas de
cada valor; el sistema suma y compara con el efectivo esperado (fondo +
cobros en efectivo). Si hay sobrante o faltante escribe la justificación.
Al cerrar se muestra el **reporte de cierre** con cada cobro y los totales
por concepto y por método, listo para **Imprimir** o **Exportar**.

**Cierre del día** y **Cierre mensual** muestran el resumen del día o del mes.

## Tareas del administrador

| Tarea | Dónde |
| --- | --- |
| Crear cajeros, desactivarlos, restablecer contraseñas | Cajeros y cierres |
| Revisar cualquier caja, cierre del día o del mes (por cajero o de todos) | Cajeros y cierres |
| Cambiar tarifas, recargo, ciclo de pago y días de aviso | Configuración |
| Crear o desactivar diplomados y horarios | Diplomados / Horarios |
| Editar una inscripción (horario, plan, fecha de inicio antes del primer cobro) | Inscripciones → Editar |
| Anular una inscripción o un comprobante (con motivo) | Inscripciones → Anular / Caja y cobros → Anular |
| Ver quién hizo qué y cuándo | Bitácora |

El administrador también puede matricular y cobrar, con su propia caja.

## Estado de cuenta del estudiante

**Estudiantes** o **Inscripciones → Estado de cuenta**: inscripciones, cuotas
pagadas y vencidas, saldo vencido, saldo por pagar del diplomado y cada pago
(con su comprobante). Se puede imprimir o exportar a Excel/PDF para
entregarlo al estudiante o a su responsable.

## Estados de una inscripción

| Estado | Significado |
| --- | --- |
| ACTIVA | Al día con sus colegiaturas |
| PENDIENTE | Pasaron los 28 días sin registrar el nuevo cobro |
| FINALIZADA | Pagó todas las cuotas y terminó el diplomado |
| ANULADA | Anulada por el administrador (sus pagos se conservan) |
